# Arrels per volar

Caixa d'eines de **pedagogia sistèmica** per a l'acció tutorial a **Cicle Mitjà** d'Educació Primària (3r i 4t, 8–10 anys).

Recurs pensat per a tutors i tutores, mestres i equips d'orientació. Està dissenyat per enfortir la identitat, el sentit de pertinença i el benestar emocional dels infants, integrant la història i la diversitat familiar a l'aula.

## Què inclou

- **4 fitxes de fonaments**: justificació, alineació amb el Decret 175/2022, actitud del docent sistèmic i base teòrica.
- **15 fitxes d'aula** en tres mòduls:
  - Mòdul I · *El fil invisible de la meva història* (identitat i origen, CPSAA1)
  - Mòdul II · *Som una Tribu* (grup i convivència, CPSAA3)
  - Mòdul III · *Abraçar l'error* (error i avaluació, CPSAA5)
- **3 instruments d'avaluació** formativa i qualitativa.
- **Mapa d'activitats** amb cerca per necessitat.

Cada fitxa d'aula té una guia per al docent i una fitxa imprimible per a l'alumnat, amb criteris DUA.

## Estructura de la carpeta

```
index.html              El web (una sola pàgina)
img/                    Il·lustració de la pàgina d'inici
materials/
  fonaments/            Fitxes 0.1 – 0.4
  modul-1/              Fitxes 1.1 – 1.5
  modul-2/              Fitxes 2.1 – 2.5
  modul-3/              Fitxes 3.0 – 3.4
  avaluacio/            Eines A i B
  mapa-activitats.pdf
```

## Veure'l a l'ordinador

Obre `index.html` amb el navegador. No cal instal·lar res.

## Publicar-lo amb GitHub Pages

1. Puja el contingut d'aquesta carpeta a un repositori de GitHub.
2. Al repositori, ves a **Settings → Pages**.
3. A **Build and deployment**, tria **Deploy from a branch**, la branca `main` i la carpeta `/ (root)`, i desa.
4. Al cap d'uns minuts, el web serà a `https://<el-teu-usuari>.github.io/<nom-del-repositori>/`.
